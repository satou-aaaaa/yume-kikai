# 夢の機械、入る？（yume-kikai）

入れば望む体験がつづく「夢の機械」（ノージックの経験機械）に、入るか・もう中にいたら出るかを答える学習ゲーム。聞き方を少しずつ変えて5回聞き、自分の答えと研究で多かった答えをくらべ、いまいる所に残った答えの数を見る。続けて、ノージックの3つの理由・3つの機械・どの条件で答えが変わるか・研究で多かった答えの問題を1日5問。

遊ぶ: <https://satou-aaaaa.github.io/yume-kikai/>

- 夢の機械には正解がありません。どんな暮らしを選ぶかは、人の好みだからです。
- 問題の中身は、次の3つに書いてあることだけです（2026-11-27 に読んだもの）。研究の数は大学生などに聞いた1回の結果で、人みんなの答えではありません。
  - Nozick, R. (1974). Anarchy, State, and Utopia, pp.42–45（授業用の抜粋 <https://rintintin.colorado.edu/~vancecd/phil3160/Nozick1.pdf> ）
  - De Brigard, F. (2010). If you like it, does it matter if it's real? Philosophical Psychology 23(1), 43–57 <https://doi.org/10.1080/09515080903532290>
  - Weijers, D. (2014). Nozick's experience machine is dead, long live the experience machine! Philosophical Psychology 27(4), 513–535 <https://doi.org/10.1080/09515089.2012.757889>
